Политика конфиденциальности

Какие данные обрабатывает Mono VPN и кто может получать информацию при подключении к VPN.

Последнее обновление: 27 ноября 2026 года.

1. О приложении

Mono VPN — приложение-клиент для подключения к VPN-серверам сторонних провайдеров на основании конфигураций и ссылок, предоставляемых пользователем. Mono VPN не предоставляет собственные VPN-серверы и не продаёт VPN-подписки. Для вопросов о конфиденциальности: monovpn@mail.ru.

2. Какие данные обрабатываются

Для работы приложения пользователь добавляет ссылку на подписку или данные конфигурации сервера. Приложение хранит настройки, выбранный сервер и служебное состояние подключения на устройстве с использованием Связки ключей (Keychain) и защищённых локальных файлов. Эти данные не отправляются разработчику, не синхронизируются разработчиком и не используются для аналитики или рекламы.

3. Передача информации третьим лицам

Для получения или обновления подписки Mono VPN обращается по адресу, который указал пользователь. В результате поставщик подписки может получить IP-адрес устройства, время обращения и технические данные запроса.

При VPN-подключении сетевые соединения проходят через выбранный сервер стороннего VPN-провайдера, за исключением трафика, который направляется напрямую по локальным правилам или правилам конфигурации провайдера. Провайдер VPN может обрабатывать IP-адрес, метаданные подключений и передаваемый трафик в соответствии со своей политикой.

Для разрешения доменных имён приложение может использовать Cloudflare DNS (1.1.1.1), Google DNS (8.8.8.8) или DNS, заданный конфигурацией провайдера. В стандартной конфигурации запросы к этим DNS-сервисам направляются через VPN-сервер. При прямой маршрутизации, указанной провайдером, правила могут отличаться. Эти сервисы могут обрабатывать DNS-запросы в соответствии со своими правилами.

4. Какие сведения получает разработчик

Приложение не содержит рекламных SDK, инструментов отслеживания поведения и аналитики. Разработчик не получает журналы посещённых сайтов, историю DNS-запросов или содержимое VPN-трафика через приложение. Mono VPN не ведёт собственный серверный сбор таких данных.

Если пользователь самостоятельно обращается в поддержку по электронной почте, разработчик получает содержание сообщения, адрес отправителя и информацию, добровольно указанную пользователем. Эти сведения используются только для ответа и решения обращения.

5. Локальное хранение и удаление

Ссылки на подписки и параметры серверов хранятся на устройстве в Keychain и локальных защищённых файлах. Файлы конфигураций исключены из резервного копирования; ключевые элементы Keychain настроены без синхронизации через iCloud. Удаление приложения не всегда автоматически удаляет записи Keychain в iOS. Данные могут сохраняться после удаления приложения и вновь стать доступны после переустановки. Для очистки сохранённых данных используйте соответствующие функции приложения, если они доступны, либо обратитесь в поддержку за инструкцией.

6. Диагностика

В релизной версии Mono VPN отключено подробное журналирование Xray, включая журналы доступа и DNS-запросов. Приложение может хранить на устройстве минимальные служебные сведения о состоянии подключения и очищенные сообщения об ошибках, необходимые для работы приложения и виджета.

7. Дети

Приложение не предназначено специально для детей и не содержит отдельного механизма регистрации детей.

8. Изменения политики

Политика может обновляться при изменении функций приложения. Актуальная версия доступна по этой странице.

9. Контакты

По вопросам конфиденциальности: monovpn@mail.ru.

Эта политика описывает приложение Mono VPN, а не услуги сторонних VPN-провайдеров. Перед подключением ознакомьтесь с условиями и политикой своего провайдера.
